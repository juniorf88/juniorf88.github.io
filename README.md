## 📌 Sobre o Projeto

Este repositório contém o código-fonte do meu website e portefólio pessoal, acessível em [juniorferreira.dev.br](https://juniorferreira.dev.br). 

O projeto foi concebido para centralizar os meus projetos, partilhar o meu percurso de aprendizagem e facilitar o contacto profissional com a comunidade e recrutadores.

---

## 🧭 Estrutura do Site

* **Início / Apresentação:** Introdução inicial com botões rápidos para visualizar projetos e opções de contacto.
* **Sobre:** Informações detalhadas acerca do meu perfil e motivações.
* **Jornada:** A minha trajetória, evolução técnica e percurso na programação web.
* **Projetos:** Montra dos trabalhos e desafios desenvolvidos.
* **Contacto:** Canais para envio de mensagens e redes sociais.
* **Tema Claro / Escuro:** Suporte a alternância entre modos de visualização (Dark/Light mode).

---

## 🛠️ Tecnologias Utilizadas

* **Front-end:** HTML5, CSS3, JavaScript / TypeScript
* **Estilização:** CSS Moderno / Tailwind CSS
* **Alojamento & Deploy:** GitHub Pages & Domínio Próprio (`juniorferreira.dev.br`)
